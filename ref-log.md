# What did you learn from implementing a multi-agent workflow?
I think multi-agent workflows are very efficient and effective for returning higher-level, more accurate gen-AI responses. Having one agent that solely focuses on a single task and another agent that checks or reviews the response is somewhat like having a human-in-the-loop, since the response is being evaluated. While this is not exactly like having direct human oversight, I think it is certianly better than a single agent workflow. This is also similar to the LLM-as-a-judge framework where a LLM checks and scores a response from a generative model. Looking towards the future, I think multi-agent workflows are going to become central to a lot of coding practicies and software engineering positions. It will significantly increase people's ability to build applications very fast and efficiently.

# Challenges faced and how you addressed them.
This is not the first time I've used a multi-agent workflow, so I did not encounter any challenges. The only thing that took me a longer time was thinking of how to write the planner and reviewer prompts in a very understandable tone.

# Any creative ideas, variations, or design choices (e.g., persona roles, prompt design).
I did not take a creative route to this assignment. Instead, I moreso just stuck to the instructions and the requirements for the planner and reviewer agents. This is because I prefer AI responses to be straight to the point.
